# Technical Architecture

## Final stack
- Next.js + TypeScript
- Tailwind CSS + shadcn/ui
- Next.js Server Actions / API routes
- PostgreSQL
- Supabase Auth
- Supabase RLS
- Supabase Storage initially
- GitHub
- Hostinger for deployment
- Cloudflare for DNS/SSL
- Resend for email
- Sentry/Google Analytics as needed

## Principle
Keep business logic independent from vendor-specific services where practical.
