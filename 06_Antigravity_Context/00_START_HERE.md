Working principle:
- Do not build the entire application in one step.
- Work module-by-module.
- Do not invent requirements when the BRD is silent.
- Keep categories, questions, scoring, upload rules, dates and award editions configurable.
- Prefer simple maintainable architecture.
- Preserve security boundaries between Applicant, Verification, Admin, Super Admin and Jury.
- After each module, run tests and fix errors before moving on.
