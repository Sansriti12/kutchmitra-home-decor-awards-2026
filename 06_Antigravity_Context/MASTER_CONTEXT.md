# Kutchmitra Master Context

Kutchmitra Home & Decor Awards 2026 is a configurable awards-management platform.

It contains four main experiences:
1. Public website
2. Applicant portal
3. Admin/verification panel
4. Jury portal

Core workflow:
Public discovery → registration/login → category selection → 7-step nomination → uploads → preview → declaration/submit → nomination ID → verification → jury assignment → confidential scoring → shortlist → winner → public publication.

Initial categories:
- Architect of the Year
- Best Luxury Residence
- Best Apartment Design
- Best Renovation Project
- Best Sustainable Home
- Ultra-Luxury Residential Project of the Year
- Interior Designer of the Year
- Emerging Designer
- Best Compact Home
- Best Smart Home
- Best Themed Project of the Year
- Luxury Villa Project of the Year

The categories are initial configuration only and must not be hard-coded.

User roles:
Public Visitor, Applicant, Verification Team, Admin, Super Admin, Jury Member.

Use the approved BRD files as the source of truth for requirements.
